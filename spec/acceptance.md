# 验收标准（功能对照表）

> 逐条列出可以照着核对的行为，界面、宿主接口、安装脚本都在内。
> 面板是窗口右侧的独立浮层（不是侧边栏标签页）。

| # | 验收项 | 通过标准 |
|---|---|---|
| A1 | 面板出现 | 会话在屏且右侧边栏收起时，面板自动出现在窗口右侧（无需任何点击）；新会话草稿态（hero）不出现，发出第一条消息后才出现 |
| A2 | 环境信息正确 | 面板显示工作区路径、分支名、未提交变更统计（+新增 -删除）、未推送提交数；与终端 `git status --porcelain -b` 一致 |
| A3 | 技能与 MCP 正确 | 列出本会话调用过的技能名与 MCP 服务名（次数用 `技能 · N 次` 形式显示）；与 `/taskmonitor/data` 返回一致 |
| A4 | 产出可打开 | 列出本会话写入/修改过的文件；点击后右侧栏出现该文件预览（面板此时自动隐藏） |
| A5 | 网页查阅可打开 | 列出抓取过的 URL 与搜索过的关键词；点击 URL 后系统默认浏览器打开该页 |
| A6 | 只读安全 | 请求未注册工作区路径的 git 数据被拒（返回 `workspace-unknown`）；`open-url` 传 `file:///` 等非 http(s) 被拒 |
| A7 | 会话切换刷新 | 切换到另一个会话后，面板各块数据随之更新 |
| A8 | 无回归 | DSH 启动无插件报错；官方右侧栏文件/浏览器/终端标签页均照常工作 |
| A9 | 代码门 | `node --check dsh-task-monitor/index.js` 与 `node --check dsh-task-monitor/client.js` 均以 0 退出 |
| A10 | 提交对话框 | 环境信息块点「提交或推送」弹出对话框：显示仓库名、分支下拉、提交说明框、包含未暂存变更勾选 + 「+X -Y」统计；三个按钮（推送 / 提交并推送 / 提交） |
| A11 | 提交/推送可用 | 点「提交」真的产生一个提交（`git log` 可见、提交说明正确）；点「提交并推送」后远端分支前进；失败时对话框里给出中文原因（如"没有可提交的变更。"） |
| A12 | 后台进程 | 「后台进程」块显示本会话后台任务：命令文本可见；运行中的行右侧转圈 + 「运行中」，完成后变 ✓ 已完成；单行省略号显示 |
| A13 | 显隐规则 | 右侧边栏展开时面板自动隐藏（收起后又出现）；hero 草稿态不出现 |
| A14 | 让位不遮正文 | 面板显示时正文整体左移（会话区加 300px 右边距），聊天文字、附件卡片、头部按钮都不被面板遮住 |
| A15 | 顶部快速开关 | 会话头部右上角有一个面板图标按钮；点击一次面板隐藏且空间让回（正文恢复全宽），再点一次恢复显示 |
| A16 | 设置开关 | 设置 → 通用 出现「任务监控面板」开关；关掉后顶部按钮同步为「显示」态、面板不再出现 |
| A17 | GitHub 登录状态 | 仓库有 GitHub 远端时，提交对话框显示 GitHub 登录状态（已登录/没登录）；没登录时给出「登录 GitHub」「去注册」入口；探测过程不弹任何窗口 |
| A18 | GitHub 登录可用 | 点「登录 GitHub」后浏览器弹出 GitHub 登录页；登录/注册不限时；完成后对话框变「已登录」，后续推送免登录 |
| A19 | 一键发布 | 仓库没有远端时，对话框给出「发布到 GitHub」（仓库名 + 私有/公开 + 发布按钮）；发布后 GitHub 上出现同名仓库、本地配好 origin、当前分支已推上去；重名/没登录/没权限都有中文提示 |
| A20 | 远端失效后说真话 | 在 GitHub 删除仓库后打开提交对话框：同步状态行红字提示「远端仓库已不存在…」，不得显示绿的「本地与远端已同步」；同时出现「重新发布」区，仓库名输入框默认预填旧仓库名 |
| A21 | 换名字重新发布 | 在重新发布区改仓库名后点发布：GitHub 出现新名字仓库、本地 `git remote get-url origin` 指向新地址、当前分支已推上去；旧地址不再被推送 |
| A22 | 无远端引导 | 仓库没有任何远端时：「推送」「提交并推送」禁用且悬停有说明；发布区照常可用；点了「提交」仍只本地提交不报错 |
| A23 | 一键安装 | 空 profile 上运行 `install.ps1`：建出联接、`dependencies` 与 `dsh.profile.bundles` 登记正确（link 地址正斜杠、其余字段不动）；重复运行全部跳过（幂等）；仓库被移动/改名后重跑：联接自动重指到新位置、link 更新、bundles 不重复 |

## 边界用例（也要覆盖）
- 非 git 目录的会话：环境信息块显示「不是 git 仓库」而不是崩掉
- 本会话没有任何技能/MCP/产出/网页时：各块显示空态文案
